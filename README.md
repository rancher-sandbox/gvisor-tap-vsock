# rancher-sandbox/gvisor-tap-vsock

This is a temporary copy of [containers/gvisor-tap-vsock](https://github.com/containers/gvisor-tap-vsock) for Rancher Desktop. Its `release-0.9` branch holds v0.9.0 plus changes that Rancher Desktop needs before upstream releases them, and Rancher Desktop builds from that branch. Once an upstream release has those changes, Rancher Desktop will switch back to it, and we plan to retire this repository.

This default branch holds only this README and `.github/OWNERS`, which names the team that owns the repository. Please report bugs and send changes to [containers/gvisor-tap-vsock](https://github.com/containers/gvisor-tap-vsock).
